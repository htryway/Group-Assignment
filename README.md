# Group-Assignment
### Installation

1. Clone the repository:
```bash
   git clone https://github.com/htryway/Group-Assignment.git
   cd Group-Assignment
```

2. Install dependencies:
```bash
   npm install
```

3. Start the app:
```bash
   npx expo start
```

   If you run into caching issues or the app doesn't reflect recent changes, clear the cache first:
```bash
   npx expo start --clear
```

4. Run it:
   - Scan the QR code with the **Expo Go** app (Android) or your **Camera app** (iOS)
   - Press `a` to open in an Android emulator
   - Press `i` to open in an iOS simulator
   - Press `w` to open in a web browser
